ZeroClaw Solana Pay Terminal

A self-hosted AI agent that issues Solana Pay payment requests in chat and confirms payments on-chain — built entirely from skills, SOPs, and the stock ZeroClaw binary.

Skill

solana-pay-terminal teaches the agent to build spec-compliant Solana Pay URLs (SOL & USDC) with a fresh reference key per invoice.

SOP

payment-watch cron polls getSignaturesForAddress(reference) every 2 minutes; a signature means paid.

Tier 1 custody

The agent never holds a key — it only emits unsigned URLs and reads the chain. No plugin to audit, no funds to lose.
